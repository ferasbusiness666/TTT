# Project Overview

**What this is:** The website for Tadele Teen Talks (TTT), a teen-run news and media organization. Built by a volunteer, not a professional dev team — Claude Code does the implementation work.

**Who's involved:**
- Two co-CEOs: Ije Ezedani and Liya Tadele
- A team of teen contributors across departments (Writing, Vlogging, Creative, Social Media & Communications, etc.)
- The visual design (UI) was already built separately using Claude Design, before any backend work started

**Brand vision:** Early-2000s magazine culture meets Y2K aesthetic — Vogue-style editorial polish, NYT-level credibility. Warm cream background, pastel content cards, a mix of display / editorial / UI fonts.

**Non-negotiables:**
- Everything must be free to run — this is a non-profit with zero budget.
- The site needs to stay reliable and always-on.
- There's no professional dev team behind this, so instructions to Claude Code need to be explicit, and changes need to be easy to check (see the git workflow in `02-tech-stack-and-decisions.md`).
